Entry for the make.fun competition
[the-joke-about-the-demo-20261121-0551](https://make.fun/c/the-joke-about-the-demo-20261121-0551):
a program that writes a one-line joke about working beside AI coding agents
to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

The joke is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
No network, no randomness — the same text is written on every run.
